อัปโหลด Resume

ลากไฟล์ PDF ของผู้สมัครมาวางได้ทีละหลายไฟล์ ระบบจะวิเคราะห์ทุกไฟล์พร้อมกันและจัดอันดับให้

3
Required Keywords

คำที่ ต้องมี ใน resume เช่น python data excel — ถ้า resume ขาดคำใดคำหนึ่งจะถูกตัดออกทันที (คะแนน 0)

4
วุฒิการศึกษาขั้นต่ำ

เลือกวุฒิที่ต้องการ เช่น ปริญญาตรี — ผู้สมัครที่จบ ป.ตรี หรือสูงกว่า (ป.โท) จะผ่านเกณฑ์นี้ด้วย

5
Bonus Keywords

คำที่ มีก็ดี ไม่มีก็ไม่ตัด เช่น excel powerbi crm — ยิ่งมีตรงมาก คะแนนยิ่งสูง

6
เกณฑ์คะแนน

ตั้งค่าคะแนนขั้นต่ำที่ "ผ่าน" และ "พิจารณา" — คะแนนต่ำกว่าเกณฑ์พิจารณาจะถูกจัดเป็น "ไม่ผ่าน"

7
โหมดการวิเคราะห์

TF-IDF เท่านั้น — ฟรี 100% วิเคราะห์ด้วยอัลกอริทึมเปรียบเทียบคำ
+ Groq AI — ใส่ Groq API Key เพื่อให้ AI ช่วยวิเคราะห์เชิงลึกเพิ่ม (resume ที่คะแนน TF-IDF ต่ำเกินไปจะไม่ถูกส่งให้ AI เพื่อประหยัด token)

8
ดูผลลัพธ์

คลิกที่การ์ดผู้สมัครเพื่อดูรายละเอียดคะแนน โครงสร้าง resume และ AI insights (ถ้าใช้) ใช้ตัวกรองด้านบนเพื่อดูเฉพาะ ผ่าน / พิจารณา / ไม่ผ่าน

9
ประวัติและ Export

ผลการวิเคราะห์แต่ละครั้งจะถูกบันทึกอัตโนมัติ ดูย้อนหลังได้ที่เมนู "ประวัติ" หรือกด "Export JSON" เพื่อดาวน์โหลดผลลัพธ์

10
วิธีขอ Groq API Key (ฟรี)

1. ไปที่ console.groq.com
2. สมัครสมาชิก / เข้าสู่ระบบด้วย Google หรือ GitHub
3. ไปที่เมนู API Keys ด้านบน
4. กด Create API Key ตั้งชื่อ แล้วกดสร้าง
5. คัดลอกคีย์ที่ขึ้นต้นด้วย gsk_... (จะเห็นครั้งเดียว เก็บไว้ให้ดี)
6. นำมาใส่ในช่อง Groq API Key ที่โหมด "+ Groq AI"

Free tier ให้โควต้า 6,000 token/นาที และ 14,400 requests/วัน — เพียงพอสำหรับใช้งานทั่วไป ไม่มีค่าใช้จ่าย
